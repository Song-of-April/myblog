# My Blog

极简个人博客，基于 GitHub Pages 构建。

## 简介

这是一个使用纯 HTML + CSS 构建的极简风格个人博客项目，托管在 GitHub Pages 上，无需后端服务，零成本搭建。

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/your-username/your-username.github.io.git
```

### 2. 本地预览

直接在浏览器中打开 `index.html` 即可预览。

### 3. 部署到 GitHub Pages

1. 在 GitHub 上创建一个名为 `your-username.github.io` 的仓库（将 `your-username` 替换为你的 GitHub 用户名）
2. 将本项目的文件推送到该仓库的 `main` 分支
3. 进入仓库 Settings → Pages，选择 `main` 分支作为源
4. 等待几分钟，你的博客就会在 `https://your-username.github.io` 上线

## 自定义

- 修改 `index.html` 中的标题、文章内容和样式
- 添加新文章只需在 `<main>` 中复制 `<article>` 结构即可
- 修改 `README.md` 更新项目说明
